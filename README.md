# my1C

## 1. Интерфейс и Структура
*   **Подсистемы:** Создают разделы меню (например, «Продажи», «Склад»). 
    *   *Ошибка:* «Объект не включен ни в одну подсистему» — лечится галочкой на вкладке «Подсистемы» в свойствах объекта.
*   **Функциональные опции:** Скрывают/показывают целые блоки (Константа Булево -> Функц. опция -> Состав объектов).
*   **Роли:** Ограничивают доступ к объектам (Права на чтение/изменение).

## 2. Справочники (Хранение статичных данных)
*   **Иерархия:** Галочка «Иерархический» (появляется `Родитель`).
*   **Предопределенные:** Создаются в Конфигураторе (нельзя удалить). Код: `Справочники.СтавкиНДС.НДС18`.
*   **Табличные части:** Списки внутри элемента (Дети, Образование).
*   **Владельцы:** Подчинение одного справочника другому (Договоры принадлежат Контрагентам).

## 3. Документы (События и Движения)
*   **Проведение:** Кнопка «Провести и закрыть». Без проведения документ не влияет на отчеты.
*   **Движения:** Вкладка «Движения» -> галочка на регистр -> **«Конструктор движений»** (сам генерирует код).
    *   *Ошибка:* «Ни один из документов не является регистратором» — нужно зайти в документ и добавить движение.
*   **Расчеты в табличной части:** Пишутся в событиях `ПриИзменении` полей (Цена, Количество).
    *   *Цепочка:* Изменили Цену -> пересчитали Сумму -> пересчитали НДС -> пересчитали Всего.

## 4. Регистры (Кровеносная система)
*   **Регистры накопления:** Остатки и обороты (Склад, Деньги).
    *   *Виртуальные таблицы:* `.Остатки`, `.Обороты`, `.ОстаткиИОбороты` (1С сама их считает).
*   **Регистры сведений:** Свойства (Цены, Курсы). Могут быть периодическими.
    *   *Срез последних:* `.СрезПоследних(&Дата, Отбор)` (берет актуальное на дату).
    *   *Подчинение регистратору:* Записи только через документы (через Конструктор движений).

## 5. Программирование
*   **Контексты:**
    *   `&НаКлиенте` — быстро, интерфейс (нажатия кнопок, пересчет).
    *   `&НаСервере` — доступ к базе, медленнее.
    *   `&НаСервереБезКонтекста` — функция без доступа к форме.
*   **События формы:** `ПриСозданииНаСервере`, `ПриОткрытии`, `ПередЗаписью`, `ПриИзменении`.
*   **Итоги в подвале:** Свойство таблицы `Подвал = Истина`, у колонки `ПутьКДаннымПодвала = Таблица.Поле`.

## 6. Запросы
*   Вместо `JOIN` используем **точку**: `Товары.Номенклатура.Цена`.
*   **Левое соединение:** Галочка «Все» у главной таблицы (чтобы вывести все записи, даже без совпадений во второй).
*   **Псевдонимы:** Вкладка «Объединения/Псевдонимы» (ВыручкаОборот -> Выручка).

## 7. СКД (Система компоновки данных)
*   **Порядок:** Набор данных (Запрос) -> Ресурсы (суммы) -> Настройки (структура).
*   **Вычисляемые поля:** Формулы (например, `Выручка - Стоимость`).
*   **Иерархия в отчете:** Настройки -> Добавить группировку (Валюта) -> в нее вложить (Сотрудник).
*   **Условное оформление:** Подсветка (например, `Выручка < 700` красным).
*   **Пользовательские настройки:** Кнопка свойств -> галочка «Включать» -> режим «Быстрый/Обычный доступ».

## 8. Печать
*   Вкладка **«Макеты»** -> **«Конструктор печати»**.
*   *Добавление итогов:* Рисуем область, задаем имя (`Всего`), в ячейку пишем параметр (`ВсегоПодокументу`), в свойствах ячейки ставим `Заполнение = Параметр`.

## 🚨 Копилка ошибок (Gotchas)
1. **Кавычки из PDF:** `"День"` — стирай и пиши заново на английской раскладке.
2. **Точка перед `=`:** Ошибка `Строка. =` — убирай точку.
3. **Пустой отчет:** Проверь даты в самом отчете и параметры виртуальной таблицы.
4. **Порядок параметров:** `ДатаОкончания` должна быть выше `КонецПериода`.
5. **Галочка «Все»:** Ставится у той таблицы, откуда нужно взять ВСЕ записи.

## 1. Контексты выполнения
*   **`&НаКлиенте`** — код для интерфейса (нажатия, пересчет). Быстро, но нет доступа к базе.
*   **`&НаСервере`** — код на сервере, имеет доступ к базе. Медленнее, но мощнее.
*   **`&НаСервереБезКонтекста`** — функция без доступа к форме (только к переданным параметрам). Используется для вспомогательных вычислений.

## 2. Основные события формы
*   `ПриСозданииНаСервере` — при создании формы (для начальной настройки).
*   `ПриОткрытии` — при открытии формы.
*   `ПередЗаписью` — перед записью объекта.
*   `ПриИзменении` — при изменении значения поля (для пересчетов).

## 3. Работа с табличными частями

## 6. Строковые операции

    Поиск подстроки: СтрНайти(Строка, Подстрока)

    Замена: СтрЗаменить(Строка, "что", "на что")

    Разделение: СтрРазделить(Строка, "разделитель")

## 7. Дата и время

    Текущая дата: ТекущаяДата()

    Начало дня: НачалоДня(Дата)

    Конец дня: КонецДня(Дата)

    Добавить дни: Дата + 5 * 86400 (5 дней в секундах)

🚨 Частые ошибки

    Точка перед = — Строка. = недопустимо.

    Кавычки из PDF — всегда перепечатывай вручную (").

    Забыл Экспорт — если функция вызывается из другого модуля, она должна быть экспортной.

    Неверный контекст — код для базы (&НаСервере) не сработает в &НаКлиенте.
